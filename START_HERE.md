# Start here

1. For this phone/tablet, use the hosted app and read OFFLINE.md to save it to your Home Screen. For your PC, extract this ZIP.
2. Open index.html in Safari, Chrome, Edge, or Firefox.
3. Start in the Genetic Prowess workbench: choose a move, adjust the proposal, import QA evidence, and download a Claude handoff. The left menu opens the visual effect and character concept editors.
4. Save keeps your design in this browser. Open > Continue saved project restores it.
5. Export > Export project creates a backup file. Open > Choose project file reloads it.
6. Read UNREAL_GUIDE.md to import textures into Unreal Engine.

To add this to your GitHub repo: open the repository, select Add file > Upload files, and upload the extracted folder contents. Keep assets/, unreal/, and swift-playgrounds/ as folders. For a hosted website, enable GitHub Pages under Settings > Pages, using main / root after the files are committed.

This is a concept studio with browser previews. Real MetaHuman assets and native Niagara/animation exports are not implemented. UE 5.8 compatibility is a target and requires testing in the editor. Swift Playgrounds support is an untested wrapper starter.
