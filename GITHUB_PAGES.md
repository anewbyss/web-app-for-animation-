# Upload individual files to GitHub

This version has no subfolders. Extract forma-upload-files.zip and upload ALL extracted files using Add file > Upload files in https://github.com/anewbyss/web-app-for-animation-.

Select the individual files, including index.html, sw.js, manifest.webmanifest, the PNG icons, both TGA textures, and the remaining files. Allow replacement of existing files and commit to main. Do not upload the ZIP itself.

GitHub Pages should use main / (root). Wait for its deployment, then reload the app online and wait for Ready for offline use. If Update available appears, export unsaved work and select it. Add to Home Screen after offline setup is ready.

For a PC, the included forma-studio.zip contains the complete original folder-based app: extract that ZIP and open index.html.
