# Use Forma offline

## This phone or tablet

1. Open the live app while online and sign in if asked.
2. Wait for **Ready for offline use on this device** at the top.
3. On iPhone/iPad, open in Safari, tap Share, then Add to Home Screen. Open the new icon online once and check the ready message. On Android, tap Install app when offered, or use Chrome's install menu.
4. Open that same icon or browser URL without internet. A first-ever visit requires internet; the app must already be saved on that device.

The offline copy includes the visual editors, game workbench, reference settings, textures, guides, and PC download. It does not include Unreal Engine, licensed game assets, or your imported media.

## Your PC — no install needed

Download for PC, extract the **whole** ZIP, then double-click index.html in Chrome, Edge, or Firefox. Keep the folder together. This copy opens directly from disk and works without internet. Home Screen installation and automatic updates require the hosted HTTPS version; the disk copy does not use a service worker.

## Saves and backups

Projects and plans stay in the browser/device where you saved them. Export project or Export change plan before changing devices. Use Open project or Open change plan on the destination. Imported photos/video must be selected again; exported handoffs list their names but do not embed them. Browser storage and offline caches may be removed by device storage cleanup or private browsing. Keep exported backups.

## Updates

When online, an updated worker downloads a complete new copy in the background. Select Update available to switch to it. Export unsaved work before updating. The app does not clear project or plan saves when updating. If offline setup fails, reconnect, reload, and check the ready message; the downloaded PC copy is the fallback.
